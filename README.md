# AG2R — Antigravity Remote Interface

AG2R превращает телефон или планшет в доступный удалённый интерфейс для Antigravity IDE, работающей на компьютере. Локальный сервер получает состояние IDE через Chrome DevTools Protocol (CDP), адаптирует интерфейс для мобильного экрана и передаёт обновления через WebSocket.

```text
Antigravity IDE → CDP → локальный сервер AG2R → HTTPS/WebSocket → телефон
```

Проект ориентирован на простой запуск без терминала и на работу с клавиатурой, экранными дикторами и увеличением интерфейса.

## Поддерживаемые системы

- сервер: Windows 11, включая LTSC, Ubuntu 22.04/24.04 и Linux Mint 21/22;
- клиент: мобильные браузеры на Android и iOS.

Для работы нужны Antigravity IDE и Node.js 22.11 или новее. Python и пакет `edge-tts` необязательны и используются только для серверной нейросетевой озвучки.

## Windows

1. Дважды щёлкните `Install AG2R.cmd` и дождитесь сообщения об окончании установки.
2. На рабочем столе и в меню «Пуск» появятся ярлыки `Start AG2R`, `AG2R Status` и `Stop AG2R`.
3. Закройте Antigravity, если она была открыта обычным способом, затем используйте `Start AG2R`.

При первом запуске AG2R создаст локальный `.env`, случайный пароль и секрет сессии. Терминал для повседневной работы не требуется.

## Ubuntu и Linux Mint

1. Установите Node.js 22.11 или новее и распакуйте архив AG2R.
2. В свойствах `install-ag2r.sh` разрешите запуск файла как программы, затем откройте его двойным щелчком.
3. В меню приложений и на рабочем столе появятся `Start AG2R`, `AG2R Status` и `Stop AG2R`.
4. Закройте Antigravity, если она уже открыта без CDP, затем используйте `Start AG2R`.

Установщик и повседневные ярлыки показывают системные диалоги и не требуют терминала. Если Antigravity установлена в нестандартный каталог, задайте полный путь в `ANTIGRAVITY_BIN` внутри `.env`.

Автоматический жизненный цикл лаунчеров проверяется на Ubuntu 22.04 и 24.04 — базовых системах для Linux Mint 21 и 22. Проверка с Orca и реальной установкой Antigravity остаётся ручной.

## Подключение телефона

1. Запустите AG2R ярлыком.
2. Откройте `AG2R Status` и найдите адрес для телефона и пароль.
3. Подключите телефон к той же Wi-Fi сети и откройте указанный HTTPS-адрес.
4. При первом подключении браузер предупредит о локальном самоподписанном сертификате.

AG2R не включает внешний туннель по умолчанию. Не публикуйте порт сервера в интернет без дополнительной сетевой защиты.

## Разработка и проверки

```bash
npm ci
npm run check
npm start
```

`npm run check` проверяет синтаксис и запускает тесты на встроенном тестовом раннере Node.js.
На Linux команда `npm run check:linux` дополнительно проверяет установку ярлыков и полный жизненный цикл сервера.

Основные каталоги:

- `server.js` — HTTPS/HTTP, WebSocket, авторизация и жизненный цикл;
- `src/cdp/` — захват интерфейса и действия через CDP;
- `src/routes/` — локальный API;
- `public/` — мобильная PWA;
- `scripts/windows/` — установщик и системные лаунчеры;
- `scripts/linux/` — установщик, desktop-файлы и системные лаунчеры;
- `test/` — автоматические тесты.

Подробнее: [архитектура](ARCHITECTURE.md), [безопасность](docs/SECURITY.md), [доступность](docs/ACCESSIBILITY.md), [участие в разработке](CONTRIBUTING.md).

## Ограничения

- Интеграция зависит от DOM Antigravity и может потребовать адаптации после обновления IDE.
- Самоподписанный сертификат не считается публично доверенным.
- Полная совместимость с каждым экранным диктором проверяется отдельно; текущий статус указан в документе о доступности.
