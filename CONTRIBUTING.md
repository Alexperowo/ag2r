# Участие в разработке AG2R

## Подготовка

Требуются Node.js 22+ и локальная копия проекта.

```bash
npm ci
npm run check
```

Для ручной разработки запустите Antigravity с CDP на `127.0.0.1:9000`, затем выполните `npm run dev`.

## Требования к изменениям

- Не добавляйте `.env`, сертификаты, журналы и локальные отчёты.
- Не используйте произвольный `eval` в production-маршрутах.
- Не открывайте CDP во внешнюю сеть.
- Сохраняйте управление с клавиатуры и доступные имена элементов.
- Добавляйте тесты для исправлений безопасности и серверной логики.
- Запускайте `npm run check` перед commit.
- При изменении Linux-лаунчеров запускайте `npm run check:linux` в Linux.

Предпочтительны небольшие commit с одной понятной причиной изменения. Pull request должен описывать пользовательский сценарий, риски и способ проверки.
